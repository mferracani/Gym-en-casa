# Entrena Casa

Aplicación web mobile-first para gestionar entrenamiento de fuerza en casa. El Sprint 1 implementa la pantalla `Hoy` con datos mock locales y una base preparada para crecer por etapas.

## Desarrollo

```bash
npm install
npm run dev
```

Abrí http://localhost:3000.

## Verificación

```bash
npm test
npm run lint
npm run typecheck
npm run build
```
