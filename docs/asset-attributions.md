# Atribuciones de assets

## Estado actual

Las láminas de ejercicios fueron generadas específicamente para Entrena Casa. La
primera serie de `Pecho + bíceps` fue aprobada por el usuario; el catálogo ampliado
se integra a la aplicación local para revisión funcional. Antes de una publicación
externa corresponde revisar similitud y validar la técnica con un profesional del
entrenamiento.

La aplicación sirve únicamente derivados `.webp` optimizados (3,2 MB en total).
Los `.png` de alta resolución se retiraron del árbol del proyecto después de
verificar los derivados, por lo que no forman parte del build ni del deploy. La
tabla registra los assets de producción que permanecen en la aplicación.

## Registro obligatorio para futuros assets

Por cada recurso incorporar:

- nombre de archivo;
- autor o entidad responsable;
- URL exacta de origen;
- licencia exacta y enlace a sus términos;
- fecha de consulta;
- texto de atribución requerido;
- modificaciones realizadas.

RepDB o Wikimedia Commons son posibles fuentes, pero cada recurso debe validarse de forma individual antes de integrarlo.
